## Skills, Tools & Tech Stack Used

### Core Engineering & Graphics Skills Demonstrated
- **Procedural 3D Geometry & Mechanical Rigging** — `LatheGeometry` machined turntables, articulated robotic arms, spring-damped micro-probes, and zero-allocation dynamic Bezier hydraulic hoses
- **Analytic 3D Inverse Kinematics (IK)** — 2-link analytical IK solver with pole-vector steering, servo micro-jitter, and critically damped settle dynamics
- **Custom GLSL Shader Programming** — View-angle Fresnel thin-film rainbow iridescence, flowing pool-to-dome current pulses, voltage-ramped gold-to-white-hot incandescence, scientific FLIR thermal heatmaps (`blue → green → red → white`), EMI wave surface ripples, procedural nanoscale FinFET transistor lattices, vacuum thruster plumes, atmospheric limb scattering, and expanding light shockwaves
- **High-Resolution Procedural Texture Authoring** — `2048×2048` dual-canvas etching & metadata masks (gold Taj Mahal architecture, PCB traces, vias, logic blocks, concentric die grid), seamless procedural PBR maps (brushed steel, Kapton gold foil, aluminized Mylar, lunar regolith), and per-frame animated holographic `CanvasTexture` telemetry terminals
- **Cinematic Camera Choreography & Custom Controls** — Multi-shot **GSAP** camera directing (OTS establishing, low rim orbits, extreme close-up shallow-DoF macro dollies, zenith thermal views, hero pull-backs) paired with hand-written damped spherical Free-Orbit drag/scroll controls
- **3D-to-2D Projected Telemetry HUD** — Real-time vector projection driving crisp thin cyan SVG leader lines anchored to live 3D scene elements
- **Procedural Audio Synthesis** — Zero-asset **Web Audio API** soundscapes (cleanroom electrical hum, velocity-tracked servo whirs, rising optical laser tones, harmonic handshake chirps, electric arc fault alarms, and resonant Cmaj9 verification chords)
- **Automated Visual QC & Pro Video Production** — Live browser inspection, z-fighting & depth-precision auditing, deterministic virtual-clock rendering, 6-panel QC contact sheets, and `-14 LUFS` stereo audio mastering

### Tools & Libraries Used
- **[Three.js](https://threejs.org/)** (`r128` via cdnjs & `v0.170.0` native ES modules) + **WebGL2 / GLSL**
- **[GSAP (`3.12.2`)](https://gsap.com/)** for multi-stage simulation choreography & 5-shot cinematic camera timelines
- **HTML5 Canvas 2D API & SVG** for procedural textures, live holographic terminals, and projected telemetry leader lines
- **Web Audio API** for real-time synthesized soundscapes in-browser
- **Procedural HDR Lighting & Tone Mapping** via `PMREMGenerator`, `PCFSoftShadowMap`, `EffectComposer`, `UnrealBloomPass`, and `ACESFilmicToneMapping`
- **Playwright + Headless Chrome (`ANGLE / D3D11` GPU WebGL)** + **Chrome DevTools Protocol (`Page.captureScreenshot`)** for deterministic virtual-clock capture ([`tools/record_scene.py`](./tools/record_scene.py))
- **Python (`numpy`, `wave`) + [FFmpeg](https://ffmpeg.org/)** (`libx264`, `yuv420p`, `loudnorm`, `aac 320k`, `+faststart`) for frame-accurate 1080p MP4 mastering, synced 48 kHz stereo audio, and multi-frame QC contact sheets
- **GitHub Pages** static hosting with [`index.html`](./index.html) fullscreen player and [`scenes.json`](./scenes.json) manifest

## Local Preview & Recording

### Run Locally
```bash
python -m http.server 8765
# Open http://localhost:8765/
```

### Record Any Scene to 1080p 60 FPS MP4
Requires Python 3.10+, [FFmpeg](https://ffmpeg.org/) on `PATH`, and Playwright Chromium:

```bash
pip install -r tools/requirements.txt
playwright install chromium

python tools/record_scene.py chandrayaan-3-landing.html out/chandrayaan-3-landing.mp4 --duration 27.5 --fps 60
```

## Adding More 3D Scenes

1. Drop your standalone `.html` scene file into the repository root.
2. Add an entry to [`scenes.json`](./scenes.json) (index `0` is the default auto-playing scene when opening the root URL).
